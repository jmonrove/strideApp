# Plans

Dated, point-in-time specs and plans, named `YYYY-MM-DD-<topic>.md`. **Don't edit a record after
it lands.** When a plan's decision becomes how the system works, copy that fact forward into
[`../architecture.md`](../architecture.md) or [`../coding-standards.md`](../coding-standards.md),
the docs the routing tables point to.

This repo is public. A plan must not name people, quote health data, or describe a specific
household or network: no addresses, boot IDs or BPM values. Upstream kept that kind of working
journal in the gitignored `docs/journal/` for exactly this reason. Put private working notes
there, not here.
